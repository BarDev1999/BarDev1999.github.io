Market Scanner with LLM Catalyst Analysis

In plain words

Thousands of stocks and one person. This tool checks every US stock against a clear set of rules, ranks them and explains each score in plain language. An AI model is used only to research the news behind a stock.

What it does

Scans 5,429 US stocks and ranks them against rules that can be changed at any time.

Why it matters

Reading charts by hand does not scale, and a score you cannot explain is a score you cannot trust.

What it shows about me

Testing ideas with evidence instead of opinion: scoring changes are measured before and after on 50,168 historical samples.

How it works

Choose a stage to see what it does and the reasoning behind it.

Scan

One background job downloads the whole universe once and scores each ticker in both directions, so the long and short tables always come from the same data.

Why it is built this wayThe download is the slow step and does not depend on direction. A single process-wide lock protects the data library, whose global cache corrupts under concurrent threads.
PythonyfinanceThreads

Indicators

A pure math module computes averages, ATR, oscillators, support and resistance zones, and measures of how far a move has travelled. Values are read from the last closed bar.

Why it is built this wayA half-formed bar changes all day. Reading only completed bars keeps the result stable and comparable with the charting platform.
NumPyPandas

Gates

Conditions that should never be averaged away are checked first: market regime, wrong-way direction, earnings inside the hold window, liquidity and short interest. A failed hard gate caps the score.

Why it is built this wayA weighted average is compensatory, so a strong factor can offset a fatal flaw. Gates turn pass or fail conditions into exactly that.
Rule engine

Score

Thirteen factors are blended with weights that depend on the setup type. Soft ceilings then limit states that cannot be called excellent however good the average looks, and each cap reports its reason.

Why it is built this wayCeilings express a rule as an ordering constraint. That worked where adjusting weights did not, because several factors reward the same quiet chart.
Config dataclassExplainable caps

Catalysts

For a chosen stock, Gemini with Google Search grounding summarizes what is driving it and returns the sources it used.

Why it is built this wayGrounding ties claims to retrievable sources. Keeping the LLM out of the score keeps the ranking deterministic and testable.
Gemini APISearch grounding

Explain

Ranked tables, a per-stock checklist and charts hand-written in SVG. Every sentence is aware of the trade direction.

Why it is built this wayA tool is only trusted if its explanation matches the number beside it, so explanation bugs were treated as correctness bugs.
FlaskVanilla JSSVG

Technical detail

Optional reading for engineers and hiring managers.

  • A hosted deployment fails closed: without an access password configured, every request is refused.
  • The password check uses a constant-time comparison to avoid leaking information through timing.
  • Responses set a Content Security Policy, X-Frame-Options and X-Content-Type-Options.
  • The interface has no third-party front-end dependencies, which reduces the supply chain surface.

Gates before averages

Hard conditions run first and cap the result. This fixed the original flaw, where one strong factor could mask a disqualifying one.

Judge the model on outcomes

A change is measured by replaying the engine's own stop and target bar by bar through real prices, counting the stop first when a bar touches both.

Compare on identical samples

Old and new models are scored on the same 50,168 samples, and a change must hold in both halves of the period to ship.

Keep the rejected ideas on record

A random weight search improved results in sample and collapsed out of sample, so a missing factor was built instead of tuning weights further.

  • A placebo test with a shuffled column reproduced one apparent signal exactly, so that signal was treated as an artifact and given no predictive credit.
  • A mirror test scores a reflected chart in the opposite direction. It exposed a candle factor biased toward longs, which was then fixed.
  • A full correctness audit found a crash on thinly traded stocks caused by inconsistent return shapes, now retired by returning a dictionary.
  • The same audit found the scanner could stay marked as running forever after one exception. It now always clears its state and reports the reason.

Scope, stated plainly

A scanner narrows attention. It does not forecast prices, and it never places an order. The evaluation harness exists to show how small any statistical edge is, not to promise one. This is not investment advice. I built it with Claude Code as my coding agent: I defined the requirements and acceptance criteria, reviewed the results and decided what shipped.
